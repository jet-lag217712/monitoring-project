# AGENTS.md

This repository uses the `/.ai/` directory as the canonical source of truth for all project documentation, architecture, design decisions, coding standards, and implementation guidance.

Before making any changes, AI agents **must** read the relevant documentation in `/.ai/` applicable to the task being performed.

When documentation and implementation conflict:

* Treat `/.ai/` as authoritative.
* Do not make assumptions or invent behavior.
* Surface discrepancies rather than silently resolving them.

Do not duplicate documentation contained in `/.ai/`. Any project-wide guidance should be added there instead of this file.
